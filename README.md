# ระบบแจ้งซ่อมคอมพิวเตอร์และอุปกรณ์ของวิทยาลัย

โปรเจกต์ Back-End สำหรับระบบแจ้งซ่อมคอมพิวเตอร์และอุปกรณ์ของวิทยาลัย ตามใบสถานการณ์จำลอง หน่วยที่ 1 สัปดาห์ที่ 1

## โครงสร้าง
- `src/` โครงสร้าง Back-End
- `docs/uml/` Use Case Diagram และ Class Diagram
- `README.md` รายละเอียดโครงการ

## ขอบเขต
รองรับการเข้าสู่ระบบ การแจ้งซ่อม การติดตามสถานะ การรับงาน การอัปเดตสถานะ การบันทึกผลการซ่อม การดูประวัติ การมอบหมายงาน และการจัดการข้อมูลห้อง/เครื่อง

## สถานะงาน
1. รอดำเนินการ
2. กำลังซ่อม
3. รออะไหล่
4. ซ่อมเสร็จ
